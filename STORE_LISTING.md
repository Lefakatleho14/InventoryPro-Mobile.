# InventoryPro - Store Listing

**App Name:** InventoryPro
**Short Description:** Manage inventory, sales, and stock alerts for small businesses.
**Full Description:** InventoryPro is an inventory management system designed for Durban Small Business Supplies. Key features: Role-based login (Manager, Shop Assistant), Real-time low-stock alerts, Product management (CRUD), Sales processing with printable receipts, and detailed reporting. Built with Firebase for secure authentication and real-time data sync.
**Category:** Business
**Release Notes (v1.0):** Initial release of InventoryPro. Includes secure Firebase login, real-time inventory tracking, sales order creation, and low-stock dashboard alerts.
